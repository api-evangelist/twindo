# Twindo

> Twindo (formerly Canvas, by Occipital Inc.) is a spatial intelligence platform that turns LiDAR scans captured with an iPhone or iPad into 99%-accurate, editable CAD and BIM as-built models compatible with Revit, AutoCAD, Archicad, Chief Architect, SketchUp, Vectorworks, and 2020 Design.

Twindo publishes its own machine-readable company profile (the "LLM JSON API") at https://www.twindo.com/llm-api/ — products, pricing, output formats, use cases, case studies, and resources as JSON. This llms.txt was generated by API Evangelist from that profile and the twindo catalog repo; Twindo publishes no /llms.txt of its own.

## APIs

- [Twindo LLM JSON API](https://www.twindo.com/llm-api/): Public machine-readable company/product/pricing profile served as raw JSON for LLMs and agents (linked from the site footer as "LLM JSON API").
- Platform API (private): https://api.twindo.com/v1/ — token-authenticated (Django REST Framework style); API + SDK access is an enterprise/partner offering with no public documentation.

## Products

- [Scan to CAD](https://www.twindo.com/how-twindo-works/): LiDAR iPhone/iPad scans transformed into editable CAD/BIM as-builts.
- [Plan to CAD (Beta)](https://www.twindo.com/features/twindo-plan-to-cad/): Convert existing 2D floor plans into editable 3D CAD models.
- [Point Cloud to BIM (Beta)](https://www.twindo.com/features/point-cloud-to-bim/): Convert point cloud data into structured BIM models.
- [Web Viewer](https://www.twindo.com/features/web-viewer/): Interactive 3D viewer for sharing, measuring, and annotating models in the browser.
- Integrations (SDK + API): SDK and API access for integrating Twindo reality capture and spatial data into custom workflows (enterprise/partner).
